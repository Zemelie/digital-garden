Plant a seed

To plant from this device, give it a GitHub key once. It's kept on this device only.

  1. Open GitHub → new fine-grained token.
  2. Name it Plant a seed (phone), pick an expiry.
  3. Repository access: Only select repositories → digital-garden.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate, copy, paste below.
